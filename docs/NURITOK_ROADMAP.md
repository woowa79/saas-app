# 누리톡(NURITOK) 첫 개발 계획

## 1. 서비스 방향
- 핵심 문장: 내 삶에 필요한 정보, 누리톡에서 잇다.
- 첫 이용자: 주거와 노후생활을 함께 준비하는 50~70대
- 첫 해결 과제: 내 상황에 맞는 임대주택 정보를 찾고, 신청 조건과 준비 서류를 이해해 스스로 신청할 수 있도록 돕는다.
- 장기 확장: 주거이음 → 집수리이음 → 생활이음·일/소득이음·배움이음 → 주거 선택지로서의 경매 기초정보

## 2. 첫 출시 범위
1. 누리톡 소개 및 첫 화면
2. 주거이음 메뉴
3. 임대주택 유형별 쉬운 안내
4. 공고 읽는 법과 신청 전 확인 항목
5. 신청 준비 체크리스트
6. 공식 공고·신청 페이지 연결
7. 질문/답변은 초기에는 운영자가 직접 답변하는 간단한 방식으로 시작

## 3. 첫 유료 서비스 실험
- 이름: 누리톡 임대주택 신청 준비 진단
- 제공: 관심 공고 확인, 공고별 확인 항목 정리, 준비서류 체크리스트, 신청 전 점검 안내
- 신청과 최종 제출은 이용자가 직접 진행
- 자격·당첨을 보장하지 않으며, 공고문과 공식기관 기준을 최종 확인하도록 안내
- 먼저 소수 이용자에게 시범 제공하고 실제 소요시간과 반복 질문을 확인한 뒤 가격 결정

## 4. 단계별 진행
### 1단계: 기반 점검과 분리
- 기존 AI 튜터 기능과 공통 로그인·데이터 기반 보존
- 누리톡 화면과 기능은 별도 경로/영역으로 추가
- 기존 기능 파일은 변경하기 전에 백업과 영향 범위를 확인

### 2단계: 첫 화면과 주거이음
- 큰 글씨, 쉬운 문장, 명확한 버튼
- 첫 화면 질문: “내게 필요한 주거정보는 무엇인가요?”
- 주거이음 핵심 메뉴와 신청 준비 흐름 구현

### 3단계: 실제 이용 검증
- 기존 콘텐츠 방문자를 대상으로 소규모 테스트
- 정보 찾기, 조건 이해, 체크리스트 사용, 공식 신청 페이지 이동 여부 확인
- 사용자의 질문을 모아 콘텐츠와 기능 개선

## 5. 운영 원칙
- 한 번에 한 단계씩 진행하고, 매 단계에서 작동 여부를 확인한다.
- 초기에는 불필요한 유료 API와 복잡한 자동화를 도입하지 않는다.
- 개인 인증서·비밀번호·금융정보를 수집하지 않는다.
- 공고별 기준과 게시일/확인일을 표시하고 공식 출처를 연결한다.
- 경매·집수리는 장기 확장 항목으로 보존하되, 첫 출시 범위에는 넣지 않는다.

## 6. 현재 코드 작업 기준
- 저장소: woowa79/saas-app
- 작업 브랜치: multi-service-platform
- main 브랜치는 보호하고, 기존 AI 튜터 홈 화면과 기능을 덮어쓰지 않는다.
- 첫 구현은 별도 누리톡 경로에서 시작한다.
